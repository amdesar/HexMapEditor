# Łączenie heksów / merge heksów

Status: pomysł do rozważenia, nie zatwierdzona implementacja. Zakres i wersja realizacji nieustalone. Nie implementowane w0.6.3; nie zmieniamy teraz geometrii, sąsiedztwa, regionów wiadra, zapisu ani historii mapy.

Przy omawianiu konceptu można rozważyć wspólny gradient większego połączonego obszaru. To odrębna możliwość od obecnego gradientu każdego heksa. Zachowane osobne backlogi: lokalne ustawienia i przebudowa górnego paska, lewy/prawy panel, kolejka importu z folderów, zakładki oraz UX zapisów presetów. Nie realizujemy ich przy okazji gradientów.
