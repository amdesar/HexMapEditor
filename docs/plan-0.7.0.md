# Plan HexMapEditor 0.7.0

## Baza

HEAD `43708ee`, implementacja 0.6.4 `45f3481` potwierdzone. Początkowy Git czysty. Odczytano raport 0.6.4, sekcję 39 specyfikacji i ścieżki gumki/kamery/persistencji. Brak instrukcji AGENTS.md w repozytorium. Bez dawnych kampanii, prywatnych danych, sprzątania i realizacji backlogów.

## Etapy i model

1. Zmierzyć osobno końcowe Exclude/serializację/walidację/historię i blokadę UI. Najpierw ograniczyć nadmiar; dokładny wynik przygotowywać poza UI na odłączonej migawce, z jedną ograniczoną operacją, kontrolą tożsamości dokumentu/rewizji i atomowym zastosowaniem. Zamrożone Freezables WPF można współdzielić; GDI i mutowalne modele nie mogą być współdzielone między workerem i UI. Jawny stan przetwarzania/anulowania i ochrona konfliktujących akcji, bez cichej utraty kliknięć.
2. Kamera mapy wewnątrz płótna: ten sam reprezentatywny rysunek, zoom/pan, cache widoku i alokacje. Ograniczona kontrola grubych łączeń, bez nowej semantyki gradientu. Dokładny obraz po interakcji, bez kolejki kamer i bez nowego globalnego timera.
3. Sesyjny High/Low: High domyślnie i po udanym Nowa/Otwórz. Średnia ważona alpha z deterministycznego małego podglądu właściwego heksa/kadru/orientacji, ograniczony cache kolorów. Low pomija tło, upraszcza warianty i rysik/wskaźnik, bez zmiany danych, faz, masek lub flag warstw. Format map11/preset4 pozostaje, jeśli nie powstają nowe dane autorytatywne.
4. Jedna procesowa historia 12 jednolitych kolorów (2×6), dopisanie tylko po OK jednolitego pickera; gradient nie zapełnia historii. Czytelny lokalny stan przełączników, bez przebudowy motywu.
5. Start/MRU: lekki ekran startowy, wspólne istniejące ścieżki Nowa/Otwórz, argument mapy pomija start. Lokalny mały plik ścieżek obok EXE (poza Library i mapą), max30, pokaż5 dostępnych, bez blokowania startu sprawdzaniem sieci. Walidacja błędów i atomowy zapis historii. Nie ładować pełnej biblioteki przed wyborem projektu.
6. Celowane pojedyncze Case (bez Run-AllTests), finalny zwykły EXE/hash/UI, raport i dokumentacja oraz aktualizacja planu wydań. Wersję 0.7.0 i finalny artefakt oznaczyć dopiero po ukończeniu zakresu.

## Punkt wznowienia

Wykonane tylko odczyty i plan. Pozostałe wszystkie etapy. Testów 0.7.0 brak. Ostatnia niepewna operacja: brak. Nie uruchamiano własnych procesów/dialogów; przed UI ustalić rzeczywisty stan. Główny EXE pozostaje ukończonym 0.6.4. Nie powtarzać audytu bazy.
